# @outlyne/mobile

Expo app for Outlyne. Routes live in `src/app` (Expo Router). Shared types,
tokens and formatters come from `@outlyne/core`.

```bash
npm install            # from the repo root
cd apps/mobile
npx expo start --ios   # Expo Go in the iOS Simulator
npx tsc --noEmit
npx expo lint
npx expo-doctor
```
